head.title: ".output/"
navigation.icon: i-vscode-icons-folder-type-package
---

::important
应将此目录添加到你的 [`.gitignore`](/docs/directory-structure/gitignore) 文件中，以避免将构建输出推送到你的仓库。
::

使用此目录将你的 Nuxt 应用部署到生产环境。

:read-more{to="/docs/getting-started/deployment"}

::warning
不要触碰其中的任何文件，因为运行 [`nuxt build`](/docs/api/commands/build) 时会重新创建整个目录。
::
