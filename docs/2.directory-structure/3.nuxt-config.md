`nuxt.config` 文件的扩展名可以是 `.js`、`.ts` 或 `.mjs`。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  // 我的 Nuxt 配置
})
```

::tip
`defineNuxtConfig` 辅助函数全局可用，无需导入。
::

如果你愿意，也可以显式从 `nuxt/config` 导入 `defineNuxtConfig`：

```ts twoslash [nuxt.config.ts]
import { defineNuxtConfig } from 'nuxt/config'

export default defineNuxtConfig({
  // 我的 Nuxt 配置
})
```

::read-more{to="/docs/api/configuration/nuxt-config"}
在 **Nuxt 配置**文档中探索所有可用选项。
::

为确保配置保持最新，Nuxt 在检测到主配置文件、[`.env`](/docs/directory-structure/env)、[`.nuxtignore`](/docs/directory-structure/nuxtignore) 和 [`.nuxtrc`](/docs/directory-structure/nuxtrc) 点文件发生更改时，会执行完整重启。
