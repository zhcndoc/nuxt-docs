`test/` 目录是存放应用程序测试的推荐位置。Nuxt 不会像扫描 `app/` 或 `server/` 那样扫描该目录；你可以自行选择测试运行器和目录结构（通常使用 [`@nuxt/test-utils`](/docs/4.x/getting-started/testing)）。

一种常见的目录结构是按环境分类：

```bash [目录结构]
-| test/
---| e2e/
---| nuxt/
---| unit/
```

- `test/unit/` — 不使用 Nuxt 运行时的快速 Node 测试
- `test/nuxt/` — 需要 Nuxt 运行时环境的测试
- `test/e2e/` — 针对运行中应用的端到端测试
