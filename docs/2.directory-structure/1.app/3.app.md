::tip
如果你有一个 `app/pages/` 目录，`app.vue` 文件是可选的。Nuxt 会自动包含一个默认的 `app.vue`，但你仍然可以添加自定义的 `app.vue` 来根据需要定制结构和内容。
::

## 用法

### 最小用法

使用 Nuxt 时，[`app/pages/`](/docs/directory-structure/app/pages) 目录是可选的。如果该目录不存在，Nuxt 将不会包含 [vue-router](https://router.vuejs.org) 依赖。这对于构建着陆页或不需要路由的应用很有用。

```vue [app/app.vue]
<template>
  <h1>Hello World!</h1>
</template>
```

:link-example{to="/docs/examples/hello-world"}

### 与页面一起使用

当你有一个 [`app/pages/`](/docs/directory-structure/app/pages) 目录时，需要使用 [`<NuxtPage>`](/docs/api/components/nuxt-page) 组件来显示当前页面：

```vue [app/app.vue]
<template>
  <NuxtPage />
</template>
```

你也可以直接在 `app.vue` 中定义应用的公共结构。当你想包含全局元素（例如页眉或页脚）时，这非常有用：

```vue [app/app.vue]
<template>
  <header>
    Header content
  </header>
  <NuxtPage />
  <footer>
    Footer content
  </footer>
</template>
```

::note
请记住，`app.vue` 是你 Nuxt 应用的主组件。你添加到其中的任何内容（JS 和 CSS）都会是全局的，并包含在每个页面中。
::

::read-more{to="/docs/directory-structure/app/pages"}
详细了解如何使用 `app/pages/` 目录来组织页面。
::

### 与布局一起使用

当你的应用需要为不同页面使用不同布局时，可以将 `app/layouts/` 目录与 [`<NuxtLayout>`](/docs/api/components/nuxt-layout) 组件搭配使用。这样你就可以定义多个布局，并将其应用于各个页面。

```vue [app/app.vue]
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

::read-more{to="/docs/directory-structure/app/layouts"}
详细了解如何使用 `app/layouts/` 目录来组织布局。
::
