# E2002

`navigateTo()` 收到了一个使用危险协议（`javascript:`、`data:`、`vbscript:`）的 URL。Nuxt 会阻止这些协议以防止 XSS。这几乎总是意味着未经过滤的用户输入传递到了 `navigateTo()`。

## 解析

在导航之前验证并清理用户提供的 URL。仅允许 `http:`、`https:` 或相对路径。
