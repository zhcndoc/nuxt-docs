# E2003

`abortNavigation()` 在路由中间件之外被调用。它只能在中间件处理程序内部取消导航，因此在组件、插件、可组合函数中调用它，或在丢失了中间件上下文的回调中调用它都会失败。

## 解决方案

将 `abortNavigation()` 调用移到 `defineNuxtRouteMiddleware()` 处理器的主体中。
