# E2003

`abortNavigation()` 在路由 middleware 之外被调用。它只能在 middleware 处理程序内部取消导航，因此从组件、插件、composable，或在失去 middleware 上下文的回调中调用它都会失败。

## 解决方案

将 `abortNavigation()` 调用移入 `defineNuxtRouteMiddleware()` 处理器的主体中。
