# E3009

调用 `useAsyncData()` 时没有传入处理函数。处理函数负责执行获取并返回数据，因此不能省略，也不能使用其他类型。

## 分辨率

```ts
const { data } = useAsyncData('users', () => $fetch('/api/users'))
```
