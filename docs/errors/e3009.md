# E3009

`useAsyncData()` 的调用未传入处理函数。处理函数是执行获取并返回数据的函数，因此不能省略，也不能是其他类型。

## 解析

```ts
const { data } = useAsyncData('users', () => $fetch('/api/users'))
```
