# E2001

`navigateTo()` 收到了一个外部 URL，但没有提供 `{ external: true }` 选项。Nuxt 要求外部导航必须显式启用，以避免意外将用户重定向到你的应用之外。

## 分辨率

```ts
navigateTo('https://example.com', { external: true })
```
