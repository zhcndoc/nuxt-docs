# E2001

`navigateTo()` 接收到了一个外部 URL，但没有提供 `{ external: true }` 选项。Nuxt 需要显式启用外部导航，以避免意外将用户重定向到你的应用之外。

## 解析

```ts
navigateTo('https://example.com', { external: true })
```
