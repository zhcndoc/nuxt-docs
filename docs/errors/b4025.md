# B4025

模板包含一个 `<NuxtLink>`，其静态 `to`（或 `href`）与任何页面路由都不匹配，因此跟随该链接会显示 404 页面。

除非禁用了 [`experimental.templateDiagnostics`](/docs/guide/going-further/experimental-features#templatediagnostics)，否则会报告此警告。只检查静态绝对路径：带绑定值的 `:to`、外部 URL、相对路径、仅包含 hash 或查询参数的链接，以及带有 `external` prop 的链接均不会检查。动态路由片段和全捕获路由可以匹配任意值；会被路由规则重定向的路径也会被接受。

如果某个路径只能匹配路由的前缀，也会报告警告：若只有 `app/pages/users/[id].vue`，指向 `/users` 的链接就没有可渲染的页面。

## 解决方案

检查路径是否有拼写错误，或添加链接所指向的页面。如果链接指向的不是页面（例如服务器路由、`public/` 中的文件，或同一域名下的另一个应用），请设置 `external` prop，让浏览器而不是 Vue Router 跟随该链接：

```vue
<template>
  <NuxtLink
    to="/api/export.csv"
    external
  >
    Download
  </NuxtLink>
</template>
```
