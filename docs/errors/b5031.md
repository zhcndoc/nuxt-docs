# B5031

加载配置时，Nuxt 会从[标准 JSON Schema](https://standardschema.dev/json-schema)中读取[运行时配置架构](/docs/guide/going-further/runtime-config#validating-with-a-schema)的类型和默认值。架构本身不会包含在服务器包中。

如果架构未实现标准 JSON Schema，或架构库无法将其转换为标准格式（例如，使用了带转换的架构），就会报告此错误。此外，`runtimeConfig` 的整体架构必须描述单个对象，不能是联合类型。

## 解决方法

请使用实现标准 JSON Schema 的架构库，例如 [Zod](https://zod.dev) 或 [ArkType](https://arktype.io)。对于 [Valibot](https://valibot.dev) 架构，请使用 `toStandardJsonSchema()` 进行包装：

```ts [nuxt.config.ts]
import * as v from 'valibot'
import { toStandardJsonSchema } from '@valibot/to-json-schema'

export default defineNuxtConfig({
  runtimeConfig: {
    apiSecret: toStandardJsonSchema(v.string()),
  },
})
```

从运行时配置架构中移除转换逻辑，并在读取值的位置执行转换：

```ts [nuxt.config.ts]
import { z } from 'zod'

export default defineNuxtConfig({
  runtimeConfig: {
    allowedHosts: z.string().transform(value => value.split(',')), // [!code --]
    allowedHosts: z.array(z.string()).default([]), // [!code ++]
  },
})
```
