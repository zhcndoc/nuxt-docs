# B5003

你在 `runtimeConfig.app` 下定义了自定义键，而该命名空间是 Nuxt 为内部值保留的（例如 `baseURL` 和 `cdnURL`）。这里的自定义键可能会与 Nuxt 自身的配置发生冲突。

## 解析

将自定义键移动到 `runtimeConfig.public`（暴露给客户端）或移到顶层自定义命名空间（仅服务端）：

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    // 而不是 runtimeConfig.app.myKey
    public: {
      myKey: 'value',
    },
  },
})
```
