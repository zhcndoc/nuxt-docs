# E8007

当 `features.noScripts: 'production'`（启用 `noScripts` 时的默认值）时，脚本只会在生产构建中从渲染后的 HTML 中移除。在开发环境中，页面仍然会加载 JavaScript，因此依赖它的行为（如懒加载水合策略、服务器组件中的 `nuxt-client` 组件）在开发时看起来正常，但在部署后会悄无声息地失效。

当某个渲染路由使用了这些功能之一时，会在开发过程中发出此警告。

## 解决方案

要么从受影响的路由中移除客户端依赖，要么使用 `noScripts` 路由规则将脚本剥离的范围限定到真正静态的路由（该规则在开发环境中也会生效，因此任何问题都会立即显现）：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    '/static/**': { noScripts: true },
  },
})
```

或者，将 `features.noScripts: 'all'` 设置为在开发环境中也剥离脚本，从而使生产环境行为在开发中可见。
