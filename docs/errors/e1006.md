# E1006

`onPrehydrate()` 在未经过 Nuxt 构建管线转换的情况下运行。它需要编译时处理，并且仅在服务器上工作，因此当它从 Nuxt 不会转译的依赖项中被调用时，就会发生这种情况。

## 解决方案

将有问题的库添加到 `nuxt.config.ts` 中的 `build.transpile`，以便构建流程可以处理其 `onPrehydrate()` 调用。
