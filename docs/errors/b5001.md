# B5001

你的 Nuxt 配置中未设置 `compatibilityDate`。Nuxt 使用该日期来决定应用哪些行为默认值，因此你的项目可以在 Nuxt 和 Nitro 更新时保持稳定，而不是在不知不觉中采用新的默认值。

## 解析度

将 `compatibilityDate` 添加到你的 `nuxt.config` 中，使用今天的日期，这样你就会启用当前默认值：

```ts
export default defineNuxtConfig({
  // 使用当前日期，例如你添加这一行的当天
  compatibilityDate: 'YYYY-MM-DD',
})
```
