# B5001

你的 Nuxt 配置中未设置 `compatibilityDate`。Nuxt 使用这个日期来决定应用哪些行为默认值，这样你的项目就能在 Nuxt 和 Nitro 更新时保持稳定，而不会在不知不觉中采用新的默认值。

## 解决方案

将 `compatibilityDate` 添加到你的 `nuxt.config` 中，使用今天的日期，这样你就可以启用当前默认值：

```ts
export default defineNuxtConfig({
  // 使用当前日期，例如你添加这一行的那一天
  compatibilityDate: 'YYYY-MM-DD',
})
```
