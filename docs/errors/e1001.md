# E1001

需要 Nuxt 实例的可组合函数（`useNuxtApp()`、`useRoute()`、`useFetch()` 等）在插件、Nuxt 钩子、路由中间件或 Vue `setup()` 之外运行。最常见的触发原因是在异步回调中调用它（`setTimeout`、`.then()`、`await` 之后），此时上下文已经丢失。

## 分辨率

在 `setup()` / 插件 / 中间件的顶部同步调用可组合函数，并在之后复用捕获到的结果。对于服务端异步工作，请使用 `nuxtApp.runWithContext()` 包裹该调用。
