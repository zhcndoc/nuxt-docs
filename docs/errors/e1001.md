# E1001

一个需要 Nuxt 实例（`useNuxtApp()`、`useRoute()`、`useFetch()` 等）的 composable 在插件、Nuxt 钩子、路由中间件或 Vue `setup()` 之外运行。最常见的触发方式是在异步回调中调用它（`setTimeout`、`.then()`、`await` 之后），此时上下文已经丢失。

## 解决方案

在 `setup()` / 插件 / 中间件的顶部同步调用该可组合函数，并在后续重复使用捕获到的结果。对于服务端异步工作，请使用 `nuxtApp.runWithContext()` 包装该调用。
