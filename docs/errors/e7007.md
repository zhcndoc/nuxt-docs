# E7007

`useState()` 收到了一个非函数的初始值。初始化器必须是一个函数，这样它才只会在服务端执行一次，并且其结果可以被序列化到用于 hydration 的 payload 中。

## 解析

```ts
const counter = useState('counter', () => 0)
```
