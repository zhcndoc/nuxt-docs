# E2005

`useRoute()` 在路由 middleware 内被调用（直接调用或通过另一个 composable 间接调用）。在该时刻，目标路由尚未解析，因此 `useRoute()` 可能返回意外的值；middleware 应改为将 `to` 和 `from` 路由作为参数接收。

## 解析

```ts
export default defineNuxtRouteMiddleware((to, from) => {
  // 使用 `to` / `from`，不要使用 useRoute()
})
```
