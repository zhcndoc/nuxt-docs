# E2005

`useRoute()` 在路由中间件内部被调用（直接调用或通过另一个可组合函数间接调用）。在那个时刻，目标路由尚未解析，因此 `useRoute()` 可能返回意外的值；中间件应改为通过参数接收 `to` 和 `from` 路由。

## 解析度

```ts
export default defineNuxtRouteMiddleware((to, from) => {
  // 使用 `to` / `from`，而不是 useRoute()
})
```
