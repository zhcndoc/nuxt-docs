# E5001

依赖应用清单的代码在 `experimental.appManifest` 被禁用时运行。该清单为诸如路由规则匹配以及客户端的预渲染负载检测等功能提供支持，因此必须启用它们才能正常工作。

## 解决方案

在你的 `nuxt.config` 中启用应用清单：

```ts
export default defineNuxtConfig({
  experimental: {
    appManifest: true,
  },
})
```
