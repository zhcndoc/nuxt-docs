# E1007

像 `definePageMeta()` 这样的编译期宏在运行时执行了。这些辅助函数会在 Nuxt 构建过程中被转换掉，绝不应动态运行。通常这意味着该宏是在一个 composable 或非页面组件中被调用，而不是直接在页面中调用。

## 解析度

仅在页面组件的 `<script setup>` 顶层调用该宏。它不能在 composables、条件语句或非页面组件中使用。
