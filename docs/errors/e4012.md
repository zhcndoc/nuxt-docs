# E4012

Nuxt 无法解析在渲染服务器组件（island）时返回的响应。这通常意味着服务器组件端点返回了非预期的岛屿有效负载，例如错误页面或格式错误的 HTML。

## 解决方案

检查服务器组件是否存在会阻止其渲染的错误，并确认 island 端点返回有效响应。检查 island 请求的网络响应，查看服务器实际返回了什么。
