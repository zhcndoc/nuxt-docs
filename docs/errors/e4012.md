# E4012

Nuxt 无法解析渲染服务器组件（岛屿）时返回的响应。这通常意味着服务器组件端点返回了与预期的岛屿有效载荷不同的内容，例如错误页面或格式错误的 HTML。

## 解析度

检查服务器组件中是否存在会阻止其渲染的错误，并确认 island 端点返回有效响应。检查 island 请求的网络响应，看看服务器实际返回了什么。
