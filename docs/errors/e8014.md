# E8014

服务器启动时，Nuxt 会将匹配的环境变量应用到[运行时配置](/docs/guide/going-further/runtime-config)，并根据每个配置值的类型检查结果。出现以下情况时，服务器将无法启动：

- 环境变量无法转换为对应配置值的类型（例如，数值型 `port` 却设置为 `NUXT_PORT=abc`）。
- 某个值通过[架构声明为必填](/docs/guide/going-further/runtime-config#validating-with-a-schema)，但没有默认值，也未通过环境变量设置。
- 某个值不符合其架构允许的取值。

每条错误信息都会指出运行时配置键及对应的环境变量。

## 解决方法

将错误信息中列出的环境变量设置为服务器运行时可接受的值：

```bash [Terminal]
NUXT_API_SECRET=my-secret NUXT_PORT=8080 node .output/server/index.mjs
```

如果该值并非必需，请在 `nuxt.config` 中为其设置默认值，或将其声明为可选：

```ts [nuxt.config.ts]
import { z } from 'zod'

export default defineNuxtConfig({
  runtimeConfig: {
    apiSecret: z.string().optional(),
    port: 3000,
  },
})
```
