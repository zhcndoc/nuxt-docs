# E3008

`useAsyncData()` 在调用时没有提供有效的 key。第一个参数必须是非空字符串，这样 Nuxt 才能在组件之间缓存并去重该请求。

## 解析

```ts
const { data } = useAsyncData('users', () => $fetch('/api/users'))
```
