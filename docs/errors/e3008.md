# E3008

`useAsyncData()` 在调用时未提供有效的键。第一个参数必须是一个非空字符串，这样 Nuxt 才能在组件之间缓存并去重该请求。

## 分辨率

```ts
const { data } = useAsyncData('users', () => $fetch('/api/users'))
```
