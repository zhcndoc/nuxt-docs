# E2007

`setPageLayout()` 在 SSR 期间于组件的 `setup()` 中被调用。 在服务端，布局必须在组件渲染之前确定，因此在这里更改它会产生不正确的 SSR 输出。

## 解决方案

从路由中间件中设置布局，或者使用 `definePageMeta({ layout: '...' })` 静态设置。
