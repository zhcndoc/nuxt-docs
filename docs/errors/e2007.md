# E2007

`setPageLayout()` 是在 SSR 期间从组件的 `setup()` 中调用的。在服务器端，布局必须在组件渲染之前确定，因此在这里更改它会产生不正确的 SSR 输出。

## 解决方案

通过路由中间件设置布局，或者使用 `definePageMeta({ layout: '...' })` 静态设置。
