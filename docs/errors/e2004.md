# E2004

引用了一个路由中间件（通常通过 `definePageMeta({ middleware: [...] })`），但不存在具有该名称的中间件。常见原因包括名称拼写错误，或中间件文件已被重命名或删除，但其引用未同步更新。

## 解析度

请确保名称与 `middleware/` 中的文件匹配。名称来源于文件名：`middleware/auth.ts` 会被引用为 `auth`。
