# E2004

引用了一个路由中间件（通常通过 `definePageMeta({ middleware: [...] })`），但不存在具有该名称的中间件。常见原因是名称拼写错误，或者中间件文件被重命名或删除后，没有同步更新其引用。

## 解析

确保名称与 `middleware/` 中的文件匹配。名称来源于文件名：`middleware/auth.ts` 会被引用为 `auth`。
