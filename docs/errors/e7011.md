# E7011

`useCookie()` 无法将 Cookie 序列化到 `Set-Cookie` 标头或 `document.cookie` 中。原始错误会附加在 `cause` 上。以下情况会抛出此错误：

- Cookie 名称中包含不允许出现的字符，例如空格、`;` 或 `=`；
- 自定义 `encode` 返回的值包含不允许出现在 Cookie 值中的字符；
- 属性之间不一致，例如设置了 `sameSite: 'none'`、`partitioned: true`，或使用 `__Secure-` / `__Host-` 前缀但未设置 `secure: true`，又或者 `__Host-` Cookie 设置了 `domain`；
- 属性值无效，例如 `maxAge` 不是整数。

## 解决方法

请使用有效的 Cookie 名称，确保 `encode` 返回编码后的字符串，并为需要安全属性的 Cookie 设置 `secure: true`：

```ts
const token = useCookie('token', {
  sameSite: 'none',
  secure: true,
})
```
