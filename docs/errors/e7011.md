# E7011

`useCookie()` 无法将 Cookie 序列化为 `Set-Cookie` 响应标头或 `document.cookie`。原始错误会附加到 `cause`。以下情况会触发此错误：

- Cookie 名称包含不允许的字符，例如空格、`;` 或 `=`。
- 自定义 `encode` 函数返回的值包含 Cookie 值中不允许的字符。
- 属性组合不兼容，例如设置了 `sameSite: 'none'` 或 `partitioned: true`，却未在 `__Secure-` 或 `__Host-` 前缀的名称上设置 `secure: true`；或者 `__Host-` Cookie 同时设置了 `domain`。
- 属性值无效，例如 `maxAge` 不是整数。

## 解决方法

请使用有效的 Cookie 名称，确保 `encode` 返回经过编码的字符串，并对要求安全传输的 Cookie 设置 `secure: true`：

```ts
const token = useCookie('token', {
  sameSite: 'none',
  secure: true,
})
```
