# B5033

`nuxt.options.runtimeConfig` 中的值是一个[架构](/docs/guide/going-further/runtime-config#validating-with-a-schema)。加载配置以及模块调用 `updateRuntimeConfig()` 时，Nuxt 会将架构替换为其默认值。直接赋给 `nuxt.options.runtimeConfig` 的架构不会被替换，因此读取该值的模块拿到的仍是架构本身，而不是默认值。

## 解决方法

在模块中，将架构传递给 [`updateRuntimeConfig()`](/docs/api/kit/runtime-config#updateruntimeconfig)：

```ts [module.ts]
import { defineNuxtModule, updateRuntimeConfig } from '@nuxt/kit'
import { z } from 'zod'

export default defineNuxtModule({
  setup (_options, nuxt) {
    nuxt.options.runtimeConfig.myModule = z.object({ apiKey: z.string() }) // [!code --]
    updateRuntimeConfig({ myModule: z.object({ apiKey: z.string() }) }) // [!code ++]
  },
})
```

如果问题出在第三方模块，请向该模块的作者报告。
