# E7001

请求 payload URL 时使用了一个包含主机名的完整 URL。Payload 始终从与应用相同的源提供，因此带有主机名的 URL 会指向应用之外，并被拒绝。

## 解决方案

请传入相对路径，而不是完整 URL：

```ts
loadPayload('/some-page')
```
