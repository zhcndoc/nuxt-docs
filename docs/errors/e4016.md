# E4016

当前路由匹配到一个嵌套页面，但父页面组件没有渲染 `<NuxtPage />`。Vue Router 只能在父页面的 `<NuxtPage />` 插槽中显示子页面，因此该子页面永远不会被显示。

当存在如下目录结构，且 `parent.vue` 不包含 `<NuxtPage />` 时，就会发生这种情况：

```bash [Directory Structure]
-| pages/
---| parent/
------| child.vue
---| parent.vue
```

## 解决方法

将 `<NuxtPage />` 添加到父页面组件中，这样子路由就可以在其中渲染。如果你本来并不打算创建嵌套路由，请重构你的 `pages/` 目录，使该页面不再拥有子路由。

::
