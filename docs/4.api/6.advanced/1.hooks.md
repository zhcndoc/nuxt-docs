## App 钩子（运行时）

查看 [app 源代码](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/nuxt.ts#L37) 以获取所有可用的钩子。

| 钩子                         | 参数           | 环境            | 描述                                                                                                                                                                           |
|------------------------------|---------------------|-----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `app:created`                | `vueApp`            | Server & Client | 创建初始 `vueApp` 实例时调用。                                                                                                                                     |
| `app:error`                  | `err`               | Server & Client | 发生致命错误时调用。                                                                                                                                                     |
| `app:error:cleared`          | `{ redirect? }`     | Server & Client | 发生致命错误时调用。                                                                                                                                                     |
| `vue:setup`                  | -                   | Server & Client | 初始化 Nuxt 根组件的设置时调用。此回调必须是同步的。                                                                                                 |
| `vue:error`                  | `err, target, info` | Server & Client | Vue 错误传播到根组件时调用。[了解更多](https://vuejs.org/api/composition-api-lifecycle#onerrorcaptured)。                                              |
| `app:rendered`               | `renderContext`     | Server          | SSR 渲染完成时调用。                                                                                                                                                    |
| `app:redirected`             | -                   | Server          | SSR 重定向之前调用。                                                                                                                                                        |
| `app:beforeMount`            | `vueApp`            | Client          | 挂载应用之前调用，仅在客户端调用。                                                                                                                           |
| `app:mounted`                | `vueApp`            | Client          | Vue 应用在浏览器中初始化并挂载时调用。                                                                                                                            |

| `app:manifest:update`        | `{ id, timestamp }` | Client          | 检测到应用有更新版本时调用。                                                                                                                            |
| `app:data:refresh`           | `keys?`             | Client          | 调用 `refreshNuxtData` 时调用。                                                                                                                                              |
| `link:prefetch`              | `to`                | Client          | 观察到 `<NuxtLink>` 即将预取时调用。                                                                                                                              |
| `page:start`                 | `pageComponent?`    | Client          | 在 `NuxtPage` 内部的 [Suspense](https://vuejs.org/guide/built-ins/suspense#suspense) 触发 pending 事件时调用。                                                                         |

## 渲染器钩子（运行时，服务端）{#renderer-hooks-runtime-server-side}

无论使用哪种服务器构建器，Nuxt 渲染器都会在渲染页面期间调用这些钩子。模块可通过[渲染器插件](/docs/api/kit/nitro#addrendererplugin)注册它们。Nuxt 运行在 Nitro 上时，也可以通过[服务器插件](/docs/directory-structure/server#server-plugins)在 `nitroApp.hooks` 上注册。其类型声明于 `nuxt/server` 导出的 `NuxtServerRendererHooks` 中。

| 钩子 | 参数 | 描述 |
|---|---|---|
| `render:route` | `context, { event }` | 每个请求在开始渲染前调用一次。将 `context.prefersStream` 设为 `false` 可让请求以非流式方式渲染。|
| `render:html` | `html, { event, streaming? }` | 在 HTML 文档各部分（`htmlAttrs`、`head`、`bodyAttrs`、`bodyPrepend`、`body` 和 `bodyAppend`）合并前调用。对于流式响应，会在 shell 发送前调用，并将 `streaming` 设为 `true`；对 `body` 和 `bodyAppend` 的更改会被丢弃。|
| `render:html:chunk` | `context, { event }` | 流式响应的每个 chunk 在发送前都会调用。替换 `Uint8Array` 类型的 `context.chunk` 可转换该 chunk。|
| `render:html:close` | `context, { event }` | 流式响应的 body 渲染完成、闭合标签发送前调用。向 `context.bodyAppend` 添加内容可在 body 末尾追加标记。|
| `render:document` | `context, { event }` | 所有 `render:html` 处理函数运行完毕后，对于非流式响应，会传入序列化后的 HTML 文档。替换 `context.html` 可修改文档。服务器组件不会调用此钩子。|
| `render:island` | `islandResponse, { event, islandContext }` | 服务器组件响应发送前调用。服务器组件只会在 Nitro 上渲染。|

`render:response` 是 Nitro 钩子，而不是渲染器钩子，因此只有 Nuxt 运行在 Nitro 上时才会调用，渲染器插件也无法注册该钩子。渲染器插件可以使用 `render:document` 替换序列化后的文档。

| `render:response` | `response, { event }` | 发送响应之前调用。| [response](https://github.com/nuxt/nuxt/blob/71ef8bd3ff207fd51c2ca18d5a8c7140476780c7/packages/nuxt/src/core/runtime/nitro/renderer.ts#L24), [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38) |
| `close` | - | Nitro 关闭时调用。| - |
| `error` | `error, { event? }` | 发生错误时调用。| [error](https://github.com/nitrojs/nitro/blob/d20ffcbd16fc4003b774445e1a01e698c2bb078a/src/types/runtime/nitro.ts#L48), [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38) |
| `request` | `event` | 收到请求时调用。| [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38) |
| `beforeResponse` | `event, { body }` | 发送响应之前调用。| [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38), unknown |
| `afterResponse` | `event, { body }` | 发送响应之后调用。| [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38), unknown |
