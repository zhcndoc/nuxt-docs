## 应用钩子（运行时）

查看 [app 源代码](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/nuxt.ts#L37) 以获取所有可用的钩子。

| 钩子                         | 参数                | 环境            | 描述                                                                                                                                                                           |
|------------------------------|---------------------|-----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `app:created`                | `vueApp`            | 服务端和客户端 | 在创建初始 `vueApp` 实例时调用。                                                                                                                                     |
| `app:error`                  | `err`               | 服务端和客户端 | 发生致命错误时调用。                                                                                                                                                     |
| `app:error:cleared`          | `{ redirect? }`     | 服务端和客户端 | 发生致命错误时调用。                                                                                                                                                     |
| `vue:setup`                  | -                   | 服务端和客户端 | 初始化 Nuxt 根组件的 setup 时调用。此回调必须是同步的。                                                                                                 |
| `vue:error`                  | `err, target, info` | 服务端和客户端 | Vue 错误传播到根组件时调用。[了解详情](https://vuejs.org/api/composition-api-lifecycle#onerrorcaptured)。                                              |
| `app:rendered`               | `renderContext`     | 服务端          | SSR 渲染完成时调用。                                                                                                                                                    |
| `app:redirected`             | -                   | 服务端          | SSR 重定向之前调用。                                                                                                                                                        |
| `app:beforeMount`            | `vueApp`            | 客户端          | 在挂载应用之前调用，仅在客户端调用。                                                                                                                           |
| `app:mounted`                | `vueApp`            | 客户端          | Vue 应用在浏览器中初始化并挂载时调用。                                                                                                                            |
| `app:suspense:resolve`       | `appComponent`      | 客户端          | 在 [悬念](https://vuejs.org/guide/built-ins/suspense#suspense) resolve 事件时调用。                                                                                                    |
| `app:manifest:update`        | `{ id, timestamp }` | 客户端          | 检测到应用有更新版本时调用。                                                                                                                            |
| `app:data:refresh`           | `keys?`             | 客户端          | 调用 `refreshNuxtData` 时调用。                                                                                                                                              |
| `link:prefetch`              | `to`                | 客户端          | 观察到 `<NuxtLink>` 即将进行预取时调用。                                                                                                                              |
| `page:start`                 | `pageComponent?`    | 客户端          | `NuxtPage` 内部的 [悬念](https://vuejs.org/guide/built-ins/suspense#suspense) 进入 pending 状态时调用。                                                                         |
| `page:finish`                | `pageComponent?`    | 客户端          | `NuxtPage` 内部的 [悬念](https://vuejs.org/guide/built-ins/suspense#suspense) 进入 resolved 状态时调用。                                                                        |
| `page:loading:start`         | -                   | 客户端          | 路由导航开始时（解析之前）或页面 key 变化时调用。如果页面被复用（例如在 `definePageMeta` 中使用静态 `key`），即使页面组件的 `setup()` 没有重新运行，此钩子也可能触发。 |
| `page:loading:end`           | -                   | 客户端          | `page:finish` 之后调用。                                                                                                                                                            |
| `page:transition:finish`     | `pageComponent?`    | 客户端          | 页面过渡的 [离开后](https://vuejs.org/guide/built-ins/transition#javascript-hooks) 事件之后调用。                                                                            |
| `dev:ssr-logs`               | `logs`              | 客户端          | 调用时会传入传递给客户端的服务端日志数组（如果启用了 `features.devLogs`）。                                                                      |
| `page:view-transition:start` | `transition`        | 客户端          | 调用 [实验性 viewTransition 支持已启用](/docs/getting-started/transitions#view-transitions-api-experimental)时，在调用 `document.startViewTransition` 之后触发。`transition` 参数是一个 [`ViewTransition`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition) 对象，带有可读取或修改的 `types` 属性（[`ViewTransitionTypeSet`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransitionTypeSet)）。 |

## 渲染器挂钩（运行时、服务器端）

Nuxt 渲染器在任何服务器构建器下渲染页面时都会调用这些钩子。模块从[渲染器插件](/docs/api/kit/nitro#addrendererplugin) 注册它们。当Nuxt在Nitro上运行时，[服务器插件](/docs/directory-structure/server#server-plugins)也可以在`nitroApp.hooks`上注册它们。它们的类型在 `NuxtServerRendererHooks` 上声明，从 `nuxt/server` 导出。

|钩|论点|描述 |
|---------------------|--------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `render:route`      | `context, { event }`                       | 在渲染开始之前，每个请求调用一次。放 `context.prefersStream` to `false` 在不流式传输的情况下呈现请求。                                                                                                                                                      |
| `render:html`       | `html, { event, streaming? }`              | 使用 HTML 文档的各个部分进行调用 (`htmlAttrs`, `head`, `bodyAttrs`, `bodyPrepend`, `body` 和 `bodyAppend`）在他们加入之前。对于流式响应，在发送 shell 之前调用它，其中 `streaming: true`，并更改为 `body` 和 `bodyAppend` 被丢弃。 |
| `render:html:chunk` | `context, { event }`                       | 在发送流式响应的每个块之前调用它。代替 `context.chunk`, a `Uint8Array`，对其进行改造。                                                                                                                                                             |
| `render:html:close` | `context, { event }`                       | 当流式响应的正文已呈现时（在结束标记之前）调用。推至 `context.bodyAppend` 在正文末尾添加标记。                                                                                                                             |
| `render:document`   | `context, { event }`                       | 使用非流式响应的序列化 HTML 文档进行调用，每隔 `render:html` 处理程序已运行。代替 `context.html` 改变它。不调用服务器组件。                                                                                         |
| `render:island`     | `islandResponse, { event, islandContext }` | 在发送服务器组件响应之前调用。服务器组件仅在 Nitro 上呈现。                                                                                                                                                                                       |

没有 `render:response` 挂钩。从 `render:html` 在 `event.res.headers` 上设置的响应标头与页面一起发送，并且 `render:document` 可以替换序列化文档。

## Nitro 应用程序挂钩（运行时、服务器端）

这些钩子由 Nitro 调用，因此仅当 Nuxt 在 Nitro 上运行时才可用。请参阅 [硝基](https://nitro.build/guide/plugins#available-hooks) 了解所有可用的挂钩。

|钩|论点|描述 |类型 |
|----------------|---------------------|-------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `dev:ssr-logs` | `{ path, logs }`    | 在请求周期结束时使用服务器端日志数组进行调用。 | -                                                                                                                                                                                                                          |
| `close`        | -                   | Nitro 关闭时调用。                                            | -                                                                                                                                                                                                                          |
| `error`        | `error, { event? }` | 发生错误时调用。                                            | [错误](https://github.com/nitrojs/nitro/blob/d20ffcbd16fc4003b774445e1a01e698c2bb078a/src/types/runtime/nitro.ts#L48), [事件](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38) |
| `request`      | `event`             | 收到请求时调用。                                      | [事件](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38)                                                                                                                         |
| `response`     | `response, event`   | 在发送响应之前调用。                                     | [回复](https://developer.mozilla.org/en-US/docs/Web/API/Response)                                                                                                                                                      |
