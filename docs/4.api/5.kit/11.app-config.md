## `updateAppConfig`

更新将应用到 `nuxt.options.appConfig` 的应用配置。这对于模块设置默认值很有用，这些默认值可以被用户配置覆盖。更新内容会使用 [`defu`](https://github.com/unjs/defu) 与现有配置进行合并。

### 类型

```ts
function updateAppConfig (appConfig: Record<string, unknown>): void
```

### 示例

```ts
import { defineNuxtModule, updateAppConfig } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    updateAppConfig({
      myModule: {
        option: 'value',
      },
    })
  },
})
```
