Nuxt 提供核心模块 [`@nuxt/image`](/modules/image)，可在应用中调整图片尺寸、转换图片并提供优化后的图片：

- **无缝替换：** 在原本使用 `<img>` 和 `<picture>` 的位置，改用 [`<NuxtImg>`](/docs/api/components/nuxt-img) 和 [`<NuxtPicture>`](/docs/api/components/nuxt-picture)。
- **内置图片处理：** 默认使用 [IPX](/modules/image/providers/ipx)，无需配置即可优化本地和远程图片。
- **支持 40 多种服务：** 可使用 CDN 或 CMS 的图片服务，也可[编写自己的服务提供方](/modules/image/advanced/custom-provider)，不受供应商锁定。
- **适配响应式布局：** 按屏幕尺寸和设备像素比提供相应尺寸的图片。
- **现代图片格式：** 将图片转换为 WebP 或 AVIF，并为支持这些格式的浏览器提供图片。
- **加快页面加载：** 使用原生懒加载，仅在图片进入视口时加载，并在加载期间显示占位图。
- **保持视觉稳定：** 为图片设置 `width` 和 `height`，预留显示空间，避免[布局偏移](https://web.dev/articles/cls)。

## 安装

将 Nuxt Image 模块添加到您的项目中：

```bash [Terminal]
npx nuxt add image
```

此命令会安装 `@nuxt/image`，并将其添加到 `nuxt.config` 的 `modules` 配置中。

::note
如果在开发时尚未安装该模块就使用 `<NuxtImg>` 或 `<NuxtPicture>`，Nuxt 会检测到这一情况，并提示你安装 `@nuxt/image`。
::

## 用法

使用 `<NuxtImg>` 替代 `<img>`，使用 `<NuxtPicture>` 替代 `<picture>`。这两个组件都无需手动导入：

::code-group

```vue [NuxtImg]
<template>
  <NuxtImg
    src="/nuxt.png"
    alt="Nuxt logo"
    width="300"
    height="80"
  />
</template>
```

```vue [NuxtPicture]
<template>
  <NuxtPicture
    src="/nuxt.png"
    alt="Nuxt logo"
    width="300"
    height="80"
    format="avif,webp"
  />
</template>
```

::

`src` 属性可以指向[本地图片](#local-images)或[远程图片](#remote-images)。

## 本地图片 {#local-images}

将图片存放在 [`public/`](/docs/directory-structure/public) 目录中，并通过根 URL（`/`）引用。例如，`public/profile.png` 对应的 URL 是 `/profile.png`：

```vue [app/pages/index.vue]
<template>
  <NuxtImg
    src="/profile.png"
    alt="Picture of the author"
    width="500"
    height="500"
  />
</template>
```

Nuxt Image 会将图片调整为指定的 `width` 和 `height`。浏览器也会根据这两个值在图片加载前预留空间，从而避免布局偏移。Nuxt Image 不会读取图片文件的固有尺寸，因此对于未通过 CSS 控制尺寸的图片，请务必设置 `width` 和 `height`。

默认情况下，Nuxt Image 使用在 Nuxt 服务器上运行的自托管图片优化器 [IPX](/modules/image/providers/ipx)。使用 `nuxt generate` 预渲染网站时，图片会在构建期间完成优化。

预渲染只会生成服务端渲染 HTML 中用到的图片尺寸。只在浏览器中渲染的图片（例如模态框或仅客户端组件中的图片）不会生成对应文件，因此访问其 URL 会返回 404。请将这些图片添加到 `nitro.prerender.routes`，或改用[图片服务提供方](#image-providers)。详情请参阅[静态图片](/modules/image/advanced/static-images)。

::warning
IPX 无法在 Workers 运行时中运行。部署到 Cloudflare Workers 等平台时，Nuxt Image 会直接提供原始图片，不做优化。若要启用图片优化，请配置[图片服务提供方](#image-providers)，例如 `cloudflare`。
::

::note
Nuxt Image 不会处理 [`app/assets/`](/docs/directory-structure/app/assets) 目录中的图片，因为这些图片由构建工具管理。若要将源图片存放在 `public/` 之外，请设置 [`image.dir`](/modules/image/configuration#dir) 选项。
::

## 响应式图像

使用 `sizes` 属性生成多个图片宽度，让浏览器根据屏幕选择合适的尺寸。每个值适用于指定断点及更大的屏幕。默认断点与 [Tailwind CSS 断点](/modules/image/configuration#screens)一致：

```vue [app/pages/index.vue]
<template>
  <NuxtImg
    src="/hero.jpg"
    alt="Mountains at sunrise"
    width="1600"
    height="900"
    sizes="100vw md:50vw xl:800px"
  />
</template>
```

在此示例中，图片在小屏幕上占满屏幕宽度；从 `md` 断点起占屏幕宽度的一半；从 `xl` 断点起宽度为 800 像素。Nuxt Image 会为每个尺寸分别生成 1x 和 2x 像素密度的图片，并将它们加入 `srcset`。`sizes` 属性不会设置图片的实际显示宽度，因此还需使用 CSS 设置宽度。

对于未设置 `sizes` 的图片（例如图标或头像），Nuxt Image 默认会生成 1x 和 2x 版本，使图片在高像素密度屏幕上保持清晰。若要调整像素密度，可针对单张图片使用 [`densities` 属性](/modules/image/usage/nuxt-img#densities)，或使用 [`image.densities`](/modules/image/configuration#densities) 为所有图片设置默认值。

## 图像格式

使用 `format` 属性将图片转换为现代格式：

```vue
<template>
  <NuxtImg
    src="/hero.jpg"
    alt="Mountains at sunrise"
    format="webp"
  />
</template>
```

若要为每种浏览器提供其支持的最佳格式，请使用 `<NuxtPicture>`。它会渲染一个 `<picture>` 元素，为每种格式生成一个 `<source>`，并提供 JPEG 或 PNG 等传统格式作为后备：

```vue
<template>
  <NuxtPicture
    src="/hero.jpg"
    alt="Mountains at sunrise"
    format="avif,webp"
  />
</template>
```

## 加载优先级

首屏以下的图片可以等用户滚动到附近时再加载。设置 `loading="lazy"`，即可在图片进入视口时再开始加载：

```vue
<template>
  <NuxtImg
    src="/gallery/sunset.jpg"
    alt="Sunset over the sea"
    width="400"
    height="300"
    loading="lazy"
  />
</template>
```

对页面[最大内容绘制（LCP）](https://web.dev/articles/lcp)有主要贡献的图片（例如主视觉图片）应尽早加载。使用 `preload` 属性在页面 head 中添加 `<link rel="preload">`，并为图片设置较高的获取优先级：

```vue
<template>
  <NuxtImg
    src="/hero.jpg"
    alt="Mountains at sunrise"
    width="1600"
    height="900"
    :preload="{ fetchPriority: 'high' }"
  />
</template>
```

## 占位图

若要在完整图片加载期间显示模糊的低清晰度版本，请添加 `placeholder` 属性：

```vue
<template>
  <NuxtImg
    src="/hero.jpg"
    alt="Mountains at sunrise"
    width="1600"
    height="900"
    placeholder
  />
</template>
```

`<NuxtImg>` 会在浏览器中用完整图片替换占位图，因此此功能需要 JavaScript。若未运行 JavaScript，页面会一直显示占位图。

你也可以提供自己的占位图，或设置其尺寸、质量和模糊度。所有可用选项请参阅 [`placeholder` 属性](/modules/image/usage/nuxt-img#placeholder)。

## 远程图像 {#remote-images}

若要使用远程图片，请将其 URL 传给 `src` 属性：

```vue [app/pages/index.vue]
<template>
  <NuxtImg
    src="https://images.unsplash.com/photo-1501785888041-af3ef285b470"
    alt="Lake surrounded by mountains"
    width="500"
    height="500"
  />
</template>
```

为避免其他网站利用你的服务器优化任意网络图片，Nuxt Image 只会优化来自允许域名的远程图片。请在 `nuxt.config` 的 `image.domains` 选项中添加这些域名：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/image'],
  image: {
    domains: ['images.unsplash.com'],
  },
})
```

使用默认的 IPX 服务提供方时，来自其他域名的图片会以原始 URL 渲染，不做优化。其他[服务提供方](#image-providers)可能采用不同的处理方式。

## 图片服务提供方 {#image-providers}

如果图片已托管在图片 CDN 或无头 CMS 上，Nuxt Image 可以使用其图片转换服务，而不是 IPX。Nuxt Image 支持[40 多种服务提供方](/modules/image/providers)，包括 Cloudinary、Imgix、Sanity 和 Storyblok。部署到 Vercel、Netlify 或 AWS Amplify 时，Nuxt Image 会自动检测并使用对应平台的图片服务。

若要使用某个服务提供方，请将其设为默认的 `provider`，并在 `nuxt.config` 中进行配置：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/image'],
  image: {
    provider: 'cloudinary',
    cloudinary: {
      baseURL: 'https://res.cloudinary.com/<your-cloud-name>/image/upload',
    },
  },
})
```

此时，图片的 `src` 就是该服务提供方上的路径：

```vue
<template>
  <NuxtImg
    src="/blog/cover.jpg"
    alt="Blog post cover"
    width="800"
    height="450"
  />
</template>
```

你也可以通过 [`provider` 属性](/modules/image/usage/nuxt-img#provider)为单张图片指定服务提供方。
