Nuxt 提供核心模块 [`@nuxt/fonts`](/modules/fonts)，用于优化 Web 字体并移除外部网络请求，从而提升隐私性和性能：

- **自托管：** Nuxt Fonts 会在构建时下载字体，再从你自己的域名提供字体文件，并使用长期缓存标头。浏览器不会向 Google 或其他字体服务发送请求。请移除从这些服务加载字体的 `<link>` 标签或 `@import` 规则，因为 Nuxt Fonts 不会处理它们。
- **减少布局偏移：** Nuxt Fonts 会调整本地系统字体，使其度量值与 Web 字体匹配。加载网络字体时，文本几乎不会移动。
- **无需编写额外代码：** 只需在 CSS 声明中指定 `font-family`。Nuxt Fonts 会找到对应字体并生成 `@font-face` 规则。

## 安装

将 Nuxt Fonts 模块添加到您的项目中：

```bash [Terminal]
npx nuxt add fonts
```

此命令会安装 `@nuxt/fonts`，并将其添加到 `nuxt.config` 的 `modules` 配置中。

## 用法

若要使用某种字体，请在 CSS 中添加 `font-family` 声明：

```vue [app/app.vue]
<template>
  <h1>Hello Nuxt Fonts!</h1>
</template>

<style scoped>
h1 {
  font-family: 'Roboto', sans-serif;
}
</style>
```

Nuxt Fonts 会检测到 `Roboto`，并从字体服务中解析该字体，随后将 `@font-face` 规则注入同一个样式表。

字体会在 CSS 中使用它的位置加载。若要将字体应用于整个应用，请在全局样式表中声明字体，并在 `nuxt.config` 的 [`css` 选项](/docs/getting-started/styling#the-css-property)中添加该样式表：

::code-group

```css [app/assets/css/main.css]
body {
  font-family: 'Inter', sans-serif;
}
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/fonts'],
  css: ['~/assets/css/main.css'],
})
```

::

Nuxt Fonts 只会解析 `font-family` 列表中的第一个字体。列表中的其他字体（例如 `sans-serif`）会用于生成后备字体的度量值。

::warning
Nuxt Fonts 只处理 CSS 样式表和 `<style>` 块，不会检测内联 `style` 属性中的 `font-family`。请参阅[未检测到的字体](#fonts-that-arent-detected)。
::

## 网页字体 {#web-fonts}

Nuxt Fonts 支持从多个 Web 字体服务获取字体，例如 [Google Fonts](https://fonts.google.com)、[Bunny Fonts](https://fonts.bunny.net)、[Fontshare](https://www.fontshare.com) 和 [Fontsource](https://fontsource.org)。无需配置服务：Nuxt Fonts 会使用第一个提供所需字体的服务。

默认情况下，Nuxt Fonts 会加载粗细范围为 `400 700` 的字体，并同时提供 `normal` 和 `italic` 样式。如果字体系列提供[可变字体](https://fonts.google.com/knowledge/introducing_type/introducing_variable_fonts)，Google Fonts 和 Fontsource 会使用可变字体。可变字体只需一个文件即可覆盖一系列粗细，而不必为每个粗细准备单独的文件。

若要加载其他粗细，或选择字体服务，请在 `nuxt.config` 的 `fonts.families` 选项中进行配置：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/fonts'],
  fonts: {
    families: [
      // Load every weight of the variable Inter font
      { name: 'Inter', weights: ['100 900'] },
      // Only load these weights of Roboto, from Google Fonts
      { name: 'Roboto', weights: [400, 700], provider: 'google' },
    ],
  },
})
```

若要为所有字体使用相同选项，请改为在 `fonts.defaults` 中设置。你还可以指定 Nuxt Fonts 加载的字符子集，例如西里尔文或阿拉伯文。完整选项请参阅[字体配置](/modules/fonts/configuration#font-options)。

## 本地字体

若要使用自己的字体文件，请将其存放在 [`public/`](/docs/directory-structure/public) 目录中。Nuxt Fonts 会扫描 `.woff2`、`.woff`、`.ttf`、`.otf` 和 `.eot` 文件，并根据 CSS 中的 `font-family` 名称匹配字体。

Nuxt Fonts 会根据文件名判断字体文件的粗细和样式。文件名未注明粗细或样式时，默认视为 `normal` 样式、`400` 粗细：

```bash [Directory structure]
-| public/
---| fonts/
-----| my-font.woff2              # 400, normal
-----| my-font-bold.woff2         # 700, normal
-----| my-font-700-italic.woff2   # 700, italic
```

然后按名称使用字体：

```css [app/assets/css/main.css]
body {
  font-family: 'My Font', sans-serif;
}
```

Nuxt Fonts 会将 `My Font` 转换为 `my-font`，以匹配对应的文件名。

对于可变字体，请在文件名中注明粗细范围，例如 `public/fonts/my-variable-font-100-900.woff2`。文件名包含 `variable` 或 `VF` 但未注明范围时，默认覆盖 `100 900`。即使使用可变字体文件，Nuxt Fonts 也只会声明[默认粗细](#web-fonts) `400 700`，其他粗细会使用该范围内最接近的值进行渲染。若要使用完整粗细范围，请配置字体：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/fonts'],
  fonts: {
    families: [
      { name: 'My Variable Font', weights: ['100 900'] },
    ],
  },
})
```

然后按名称使用字体：

```css [app/assets/css/main.css]
h1 {
  font-family: 'My Variable Font', sans-serif;
  font-weight: 900;
}
```

若要使用文件名不同于字体名称，或托管在其他位置的字体文件，请在 `fonts.families` 中设置 `src`。可以重复使用同一个字体名称，为不同粗细分别添加文件：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/fonts'],
  fonts: {
    families: [
      { name: 'Brand Font', src: '/brand-regular.woff2', weight: 400 },
      { name: 'Brand Font', src: '/brand-black.woff2', weight: 900 },
    ],
  },
})
```

## 未检测到的字体 {#fonts-that-arent-detected}

Nuxt Fonts 仅解析它在 CSS 中找到的字体。它不会检测内联样式、内联 SVG、第三方样式表中的字体或仅在运行时应用的字体。

对于这些字体，请在 `fonts.families` 中设置 `global: true`。Nuxt Fonts 随后会为字体生成 `@font-face` 规则，并将其添加到每个页面：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/fonts'],
  fonts: {
    families: [
      { name: 'Anton', global: true },
    ],
  },
})
```

每位访问者都会下载包含全局字体的 CSS，因此请仅在确有需要时启用此选项。

如果使用 `<img>` 标签，此选项不会生效，因为图片无法使用页面中的字体。请改为将字体嵌入 SVG 文件。

## Tailwind CSS

Nuxt Fonts 读取 Tailwind CSS 生成的 CSS，因此您可以将字体声明为主题变量：

```css [app/assets/css/main.css]
@import "tailwindcss";

@theme {
  --font-display: 'Inter', sans-serif;
}
```

然后使用 `font-display` 工具类应用该字体。更多详情请参阅 [Nuxt Fonts 使用指南](/modules/fonts/usage#tailwind-css)和 UnoCSS 文档。
