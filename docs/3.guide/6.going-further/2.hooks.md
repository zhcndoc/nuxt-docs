## Nuxt 钩子（构建时）

这些钩子可用于 [Nuxt 模块](/docs/guide/modules) 和构建上下文。

### 在 `nuxt.config.ts` 内

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  hooks: {
    close: () => { },
  },
})
```

### 在 Nuxt 模块中

```js
import { defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    nuxt.hook('close', async () => { })
  },
})
```

::read-more{to="/docs/api/advanced/hooks#nuxt-hooks-build-time"}
探索所有可用的 Nuxt 钩子。
::

## 应用钩子（运行时）

应用钩子主要可由 [Nuxt 插件](/docs/directory-structure/app/plugins) 用于接入渲染生命周期，但也可以在 Vue 组合式函数中使用。

```ts [app/plugins/test.ts]
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('page:start', () => {
    /* 你的代码写在这里 */
  })
})
```

::read-more{to="/docs/api/advanced/hooks#app-hooks-runtime"}
探索所有可用的应用钩子。
::

## 渲染器钩子（运行时）{#renderer-hooks-runtime}

Nuxt 渲染器会在渲染页面期间调用这些钩子，例如使用 `render:html` 在发送前修改 HTML。模块可通过渲染器插件注册这些钩子，该插件可以在任何服务器构建器下运行。

::code-group

```ts [module.ts]
import { addRendererPlugin, createResolver, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    const { resolve } = createResolver(import.meta.url)
    addRendererPlugin(resolve('./runtime/server/renderer'))
  },
})
```

```ts [runtime/server/renderer.ts]
import type { RendererPlugin } from 'nuxt/server'

export default (({ hooks }) => {
  hooks.hook('render:html', (html) => {
    html.bodyAppend.push('<hr>Appended by custom plugin')
  })
}) satisfies RendererPlugin
```

::

Nuxt 运行在 Nitro 上时，服务器插件也可以在 `nitroApp.hooks` 上注册这些钩子。

::read-more{to="/docs/api/advanced/hooks#renderer-hooks-runtime-server-side"}
查看所有可用的渲染器钩子。
::

## 服务器钩子（运行时）

这些钩子供[服务器插件](/docs/directory-structure/server#server-plugins)用于接入 Nitro 的运行时行为，因此只有 Nuxt 运行在 Nitro 上时才会调用。

```ts [~~/server/plugins/test.ts]
export default defineNitroPlugin((nitroApp) => {
  nitroApp.hooks.hook('request', (event) => {
    console.log('request', event.path)
  })

  nitroApp.hooks.hook('render:response', (response, { event }) => {
    console.log('render:response', response)
  })
})
```

::read-more{to="/docs/api/advanced/hooks#nitro-app-hooks-runtime-server-side"}
详细了解可用的 Nitro 生命周期钩子。
::

## 添加自定义钩子

你可以通过扩展 Nuxt 的钩子接口来定义自定义钩子支持。

```ts
import type { HookResult } from '@nuxt/schema'

declare module '#app' {
  interface RuntimeNuxtHooks {
    'your-nuxt-runtime-hook': () => HookResult
  }
  interface NuxtHooks {
    'your-nuxt-hook': () => HookResult
  }
}

declare module 'nitropack/types' {
  interface NitroRuntimeHooks {
    'your-nitro-hook': () => void
  }
}
```
