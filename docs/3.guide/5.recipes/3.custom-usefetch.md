当使用 Nuxt 时，你可能在构建前端并从外部 API 获取数据，你可能希望为从你的 API 获取数据设置一些默认选项。

[`$fetch`](/docs/api/utils/dollarfetch) 工具函数（由 [`useFetch`](/docs/api/composables/use-fetch) 组合式函数使用）有意不支持全局配置。这一点很重要，可以确保应用中的获取行为保持一致，并让其他集成（如模块）能够依赖 `$fetch` 等核心工具的行为。

然而，Nuxt 提供了一种方法，允许为你的 API 创建自定义的 fetcher（如果你有多个要调用的 API，也可以创建多个 fetcher）。

## 自定义 `$fetch`

假设你有一个外部 API 地址为 `https://api.nuxt.com`，它需要通过 [nuxt-auth-utils](https://github.com/atinux/nuxt-auth-utils) 使用 JWT 进行身份验证，并且你希望在收到 `401` 响应时重定向到 `/login`。

```ts [app/composables/useAPI.ts]
export const useAPI = createUseFetch({
  baseURL: 'https://api.nuxt.com',
  onRequest ({ options }) {
    const { session } = useUserSession()
    if (session.value?.token) {
      options.headers.set('Authorization', `Bearer ${session.value.token}`)
    }
  },
  async onResponseError ({ response }) {
    if (response.status === 401) {
      await navigateTo('/login')
    }
  },
})
```

现在，每次调用 `useAPI` 都会自动包含认证头，并处理 401 重定向：

```vue [app/pages/dashboard.vue]
<script setup lang="ts">
const { data: profile } = await useAPI('/me')
const { data: orders } = await useAPI('/orders')
</script>
```

## 自定义 `$fetch` 实例

如果你需要更底层的控制，可以通过 [Nuxt 插件](/docs/directory-structure/app/plugins) 创建自定义的 `$fetch` 实例，然后直接将其与 `useAsyncData` 配合使用，或传递给 `createUseFetch`。

::note
`$fetch` 是 [ofetch](https://github.com/unjs/ofetch) 的一个已配置实例，它支持添加 Nuxt 服务的基础 URL 以及在 SSR 期间直接函数调用（避免 HTTP 往返）。
::

我们这里假设：
- 主 API 是 https://api.nuxt.com
- 我们使用 [nuxt-auth-utils](https://github.com/atinux/nuxt-auth-utils) 将 JWT 令牌存储在会话中
- 如果 API 返回 `401` 状态码，我们会将用户重定向到 `/login` 页面

```ts [app/plugins/api.ts]
export default defineNuxtPlugin((nuxtApp) => {
  const { session } = useUserSession()

  const api = $fetch.create({
    baseURL: 'https://api.nuxt.com',
    onRequest ({ request, options, error }) {
      if (session.value?.token) {
        options.headers.set('Authorization', `Bearer ${session.value?.token}`)
      }
    },
    async onResponseError ({ response }) {
      if (response.status === 401) {
        await nuxtApp.runWithContext(() => navigateTo('/login'))
      }
    },
  })

  return {
    provide: {
      api,
    },
  }
})
```

通过这个 Nuxt 插件，`$api` 会从 `useNuxtApp()` 暴露出来，以便在 Vue 组件中直接进行 API 调用：

```vue [app/app.vue]
<script setup>
const { $api } = useNuxtApp()
const { data: modules } = await useAsyncData('modules', () => $api('/modules'))
</script>
```

::callout
使用 [`useAsyncData`](/docs/api/composables/use-async-data) 封装**可以避免在服务端渲染时重复获取数据**（服务器端和客户端水合时）。
::
