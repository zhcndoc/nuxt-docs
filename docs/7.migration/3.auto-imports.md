---
title: 自动导入
description:  Nuxt 3 采用最小摩擦的方式，这意味着在可能的情况下组件和可组合项会被自动导入。
---

::note
在迁移文档的其余部分，你会发现 Nuxt 和 Vue 的关键工具并没有显式导入。这不是笔误；Nuxt 会自动为你导入它们，如果你按照[说明](/docs/migration/configuration#typescript)使用 Nuxt 的 TypeScript 支持，就应该能获得完整的类型提示。
::

[进一步了解自动导入](/docs/guide/concepts/auto-imports)

## 迁移

1. 如果你在 Nuxt 2 中使用过 `@nuxt/components`，可以在 `nuxt.config` 中移除 `components: true`。如果你的配置更复杂，请注意组件选项发生了一些变化。更多信息请参阅[组件文档](/docs/directory-structure/app/components)。

::tip
你可以查看 `.nuxt/types/components.d.ts` 和 `.nuxt/types/imports.d.ts`，以了解 Nuxt 如何解析你的组件和可组合的自动导入。
::
